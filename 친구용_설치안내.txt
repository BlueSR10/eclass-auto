eClass 영상 자동 넘기기 설치 안내

서울과기대 eClass 온라인 강의를 자동으로 틀어주는 프로그램이야.
영상을 1배속으로 재생하고, 출석인정 시간을 채우면 출석(종료)를 누른 뒤 다음 영상을 알아서 열어줘.
크롬에서만 돼.


■ 설치 (처음 한 번만, 3분)

1. 크롬 웹스토어에서 Tampermonkey 설치
   https://chromewebstore.google.com 에서 "Tampermonkey" 검색 → [Chrome에 추가]

2. 사용자 스크립트 허용 켜기
   - 크롬 주소창에 chrome://extensions 입력
   - Tampermonkey의 [세부정보] 클릭
   - "사용자 스크립트 허용" 스위치 켜기
   ※ 이 항목이 안 보이면 같은 페이지 오른쪽 위의 "개발자 모드"를 켜고 다시 확인

3. 아래 링크 열기 → 뜨는 화면에서 [설치] 클릭
   https://raw.githubusercontent.com/BlueSR10/eclass-auto/main/eclass-auto.user.js

4. eClass 페이지가 열려 있었다면 새로고침


■ 사용법

1. eClass에서 과목 강의실 → 영상 항목을 눌러서 영상 목록 화면으로 들어가기
   (왼쪽에 회차 목록이 보이는 화면)
2. 오른쪽 아래 [자동 넘기기 OFF] 버튼을 눌러서 ON으로 바꾸기
3. 끝. 알아서 안 본 영상을 열고 → 재생하고 → 출석(종료) → 다음 영상으로 넘어가.
   과목 영상을 다 보면 알림이 뜨고 자동으로 꺼져.

- 영상 화면에서 켜고 끄려면 Alt+Shift+A
- 직접 영상 목록에 새로 들어가거나 왼쪽 목록을 직접 누르면 자동으로 OFF가 돼.
  다시 ON 누르면 이어서 해줘.


■ 주의

- 크롬 창을 최소화하거나 다른 탭에 오래 두면 재생이 느려질 수 있어. 창은 띄워두는 게 안전해.
- 배속은 건드리지 마. 출석인정 시간을 못 채우면 매크로가 1분씩 더 재생하느라 오히려 오래 걸려.
- "다른 기기에서 시청 중" 확인창은 매크로가 알아서 [확인]을 눌러.
- 다른 기기(폰 등)에서 동시에 보고 있으면 끊기니까 한 곳에서만 틀어놔.
- 업데이트는 Tampermonkey가 알아서 받아와.


■ 안 될 때

- 오른쪽 아래 버튼이 안 보임
  → 영상 목록 화면(왼쪽에 회차 목록이 있는 곳)인지 확인하고 새로고침
  → 크롬 오른쪽 위 Tampermonkey 아이콘을 눌렀을 때 "eClass 영상 자동 넘기기"가 켜져 있는지 확인
  → 2번(사용자 스크립트 허용)이 켜져 있는지 확인

- 링크를 열었는데 설치 화면 대신 코드 글자만 보임
  → Tampermonkey 아이콘 → [대시보드] → [+] 탭
  → 안에 있는 내용을 전부 지우고, 링크에 보이는 글자를 전부 복사해서 붙여넣기 → Ctrl+S

- 그래도 안 되면 스크린샷 찍어서 보내줘
